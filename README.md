# .github

Default community health files for the [mihnk](https://github.com/mihnk)
organization.

Every repository under `mihnk` inherits the files in this repository unless it
defines its own version of that file.

| File                                   | Purpose                                        |
| -------------------------------------- | ---------------------------------------------- |
| `profile/README.md`                    | The organization profile shown on GitHub        |
| `SECURITY.md`                          | How to report a security vulnerability          |
| `CONTRIBUTING.md`                      | What to do before opening a pull request        |
| `CODE_OF_CONDUCT.md`                   | Contributor Covenant 2.1                        |
| `SUPPORT.md`                           | Where to ask questions                          |
| `PULL_REQUEST_TEMPLATE.md`             | Pull request description template               |
| `.github/ISSUE_TEMPLATE/`              | Issue forms and their configuration             |

Issue templates must live in `.github/ISSUE_TEMPLATE/`; the other files are
read from the repository root.

Editing a file here changes the default for every repository at once. A
repository that needs something different simply adds its own copy.
