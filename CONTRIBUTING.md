# Contributing

Contributions are welcome.

Before opening a pull request:

- keep changes focused and reasonably small
- follow the existing project style and conventions
- add or update tests when relevant
- update documentation when behavior changes
- make sure all CI checks pass

For significant changes, new features, or changes in project direction,
please open an issue first to discuss the approach.

Please keep discussions constructive and follow our [Code of Conduct](https://github.com/mihnk/.github/blob/main/CODE_OF_CONDUCT.md).
